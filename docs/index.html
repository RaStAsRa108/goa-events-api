💻 Как использовать

Пример на Python:

import requests

# Получить все события
response = requests.get('https://ваш-username.github.io/ваш-репо/events.json')
data = response.json()

print(f"Всего событий: {data['total']}")
for event in data['events'][:5]:
    title = event.get('title', 'Без названия')
    city = event.get('tribe', 'unknown')
    print(f"- {title} ({city})")
